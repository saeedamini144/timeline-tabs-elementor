# تب تایم‌لاین برای المنتور

ویجت «تب تایم‌لاین» — تبدیل دیزاین `timeline-tabs.html` به یک ویجت مستقل المنتور با تنظیمات محتوا و استایل تفکیک‌شده برای هر بخش.

## نصب

۱. پوشهٔ `timeline-tabs-elementor` را در `wp-content/plugins/` کپی کنید
(یا از فایل `timeline-tabs-elementor.zip` و مسیر **افزونه‌ها ← افزودن ← بارگذاری افزونه** استفاده کنید).
۲. افزونه را فعال کنید.
۳. در ویرایشگر المنتور، ویجت **تب تایم‌لاین** را از دستهٔ «ویجت‌های تایم‌لاین» بکشید و رها کنید.

نیازمندی‌ها: وردپرس ۶٫۰+، المنتور ۳٫۵+، PHP ۷٫۴+.

## ساختار فایل‌ها

```
timeline-tabs-elementor/
├── timeline-tabs-elementor.php        بارگذار افزونه، ثبت دسته و دارایی‌ها
├── widgets/
│   └── class-timeline-tabs-widget.php کنترل‌ها و رندر ویجت
└── assets/
    ├── css/timeline-tabs.css          استایل فرانت (مبتنی بر متغیرهای CSS)
    └── js/timeline-tabs.js            منطق تب‌ها (وانیلا، بدون jQuery)
```

## تب «محتوا»

### آیتم‌های تایم‌لاین (ریپیتر)

هر آیتم = یک تب روی تایم‌لاین + یک پنل محتوا. با دکمهٔ «افزودن آیتم» تب جدید ساخته می‌شود. هر آیتم سه زبانه دارد:

| زبانه | فیلدها |
|---|---|
| **تب** | عنوان بالایی (اصلی)، عنوان پایینی، نوع نشانگر (خودکار/نقطه/آیکن/بدون)، انتخاب آیکن |
| **محتوا** | تصویر اول، تصویر دوم، ساب عنوان، عنوان اصلی، محتوا (ویرایشگر متنی کامل) |
| **استایل** | رنگ و فونت عنوان بالایی (عادی/فعال)، رنگ و فونت عنوان پایینی، رنگ نشانگر (عادی/فعال)، اندازهٔ آیکن، رنگ ساب عنوان / عنوان / متن، نسبت تصاویر همان آیتم |

مقادیر زبانهٔ «استایل» فقط همان آیتم را بازنویسی می‌کنند؛ بقیه از تنظیمات کلی تب Style ارث می‌برند.

### تنظیمات عمومی

تب فعال هنگام بارگذاری، جای تایم‌لاین (بالا/پایین محتوا)، نحوهٔ نمایش عنوان پایینی (فعال + هاور / فقط فعال / فقط هاور / همیشه)، تگ HTML هر عنوان (H1–H6، div، p، span، strong)، اندازهٔ فایل تصاویر، انیمیشن و مدت آن، اسکرول خودکار تب انتخاب‌شده، برچسب دسترس‌پذیری.

زیربخش **موبایل و لمسی**: تعویض تب با کشیدن انگشت روی بخش محتوا، محو لبه‌های تایم‌لاین هنگام اسکرول افقی و اندازهٔ آن.

## تب «Style»

هر بخش، بخش استایل مستقل خودش را دارد:

- **چیدمان کلی** — حداکثر عرض، فاصلهٔ داخلی، پس‌زمینه، کادر، گردی گوشه، سایه، فاصلهٔ تایم‌لاین از محتوا
- **خط تایم‌لاین** — رنگ/ضخامت خط، رنگ/ضخامت خط پیشرفت، پنهان‌سازی هرکدام، حداقل عرض تب، فاصلهٔ داخلی تب، پس‌زمینهٔ نوار
- **نشانگر (نقطه / آیکن)** — ارتفاع ناحیه، اندازهٔ نقطه (عادی/فعال)، گردی گوشه، رنگ نقطه و آیکن در سه حالت عادی/هاور/فعال، ضخامت و رنگ هاله، اندازهٔ آیکن، بزرگ‌نمایی آیکن فعال
- **عنوان بالایی تب** — تایپوگرافی (+ تایپوگرافی مجزای حالت فعال)، حداقل ارتفاع، حاشیه، رنگ در سه حالت
- **عنوان پایینی تب** — تایپوگرافی (+ حالت فعال)، حاشیه، شکستن خط، رنگ سه حالت، شفافیت در هاور
- **ستون‌بندی محتوا** — فاصلهٔ ستون‌ها، سهم ستون تصویر، سهم ستون متن، ترازبندی عمودی، ترازبندی متن، فاصلهٔ داخلی بخش متن، حالت شکستن چیدمان (خودکار / همیشه تک‌ستون / هرگز) و ترتیب متن و تصویر پس از شکستن
- **استایل تصویر اول / استایل تصویر دوم** (دو بخش مستقل) — عرض، نسبت ابعاد، ارتفاع ثابت، حداکثر ارتفاع، نحوهٔ برش، نقطهٔ تمرکز، رنگ کادر خالی، گردی گوشه، کادر، سایه، فیلترهای CSS، انیمیشن نمایش (و تأخیر برای تصویر دوم)
- **ساب عنوان** — رنگ، تایپوگرافی، حاشیه
- **عنوان اصلی** — رنگ، تایپوگرافی، حاشیه، حداکثر عرض
- **متن محتوا** — رنگ، تایپوگرافی، رنگ تیترهای داخل متن، رنگ لینک (عادی/هاور)، حداکثر عرض، جای کادر، فاصلهٔ پاراگراف‌ها، حاشیه
- **لوزی تزئینی** — نمایش، رنگ، اندازه، ضخامت، موقعیت افقی و عمودی

همهٔ کنترل‌های اندازه و چیدمان واکنش‌گرا هستند (دسکتاپ/تبلت/موبایل).

## رفتار واکنش‌گرا

- شکستن چیدمان با **container query** روی عرض خودِ ویجت انجام می‌شود، نه عرض صفحه؛ پس ویجت داخل یک ستون باریک المنتور هم درست می‌شکند. برای مرورگرهای قدیمی، همان قاعده‌ها با بریک‌پوینت‌های المنتور (۱۰۲۴ و ۷۶۷) تکرار شده‌اند.
  - زیر ۸۸۰ پیکسل: متن بالا می‌آید و تصویرها زیر آن قرار می‌گیرند.
  - زیر ۵۶۰ پیکسل: همه‌چیز تک‌ستون می‌شود (شامل حالت دو تصویر بدون متن).
  - با کنترل «حالت شکستن» می‌شود این رفتار را به «همیشه تک‌ستون» یا «هرگز نشکن» تغییر داد.
- حالت‌های `:hover` داخل `@media (hover:hover)` قرار دارند تا روی صفحه‌های لمسی «نچسبند». روی دستگاه لمسی، گزینهٔ «فقط هاور» برای عنوان پایینی مثل «فقط تب فعال» عمل می‌کند.
- عنوان پایینی روی موبایل به‌صورت پیش‌فرض می‌شکند تا از عرض تب بیرون نزند (کنترل «شکستن خط»، واکنش‌گرا).
- وقتی تب‌ها از عرض بیشتر شوند، لبهٔ قابل اسکرول محو می‌شود؛ تب فعالِ اولیه هم بدون انیمیشن وسط ریل می‌آید تا بیرون از کادر نماند.
- جابه‌جایی تب، به‌جای `scrollIntoView`، فقط ریل تایم‌لاین را حرکت می‌دهد تا صفحه عمودی نپرد.
- کشیدن افقی انگشت روی بخش محتوا، تب بعدی/قبلی را باز می‌کند (آگاه به RTL، قابل خاموش کردن). تصاویر تب‌های مجاور هم از پیش گرفته می‌شوند تا کادر خالی دیده نشود.
- جدول، `pre`، iframe و کلمه‌های بلند داخل متن محدود شده‌اند تا صفحه روی موبایل افقی کشیده نشود.

## رفتار «محتوای خالی نمایش داده نمی‌شود»

- عنوان بالایی، عنوان پایینی، ساب عنوان، عنوان اصلی و متن: اگر خالی باشند، تگ آن‌ها اصلاً در HTML رندر نمی‌شود.
- تصویر انتخاب‌نشده: کادر `figure` رندر نمی‌شود و ستون‌بندی خودکار تغییر می‌کند
  (دو تصویر → سه ستون، یک تصویر → دو ستون، بدون تصویر → یک ستون، دو تصویر بدون متن → دو ستون).
- آیتمی که همهٔ فیلدهایش خالی باشد، کل تب و پنلش حذف می‌شود.
- نشانگر روی گزینهٔ «بدون نشانگر»، بدون نقطه و آیکن رندر می‌شود.

## نکات بهینه‌سازی

- CSS و JS به‌صورت فایل جدا ثبت می‌شوند و از طریق `get_style_depends()` / `get_script_depends()` فقط در صفحاتی که ویجت دارند بارگذاری می‌شوند.
- استایل روی متغیرهای CSS سوار است؛ حالت‌های هاور/فعال از همان متغیرها استفاده می‌کنند و خروجی CSS المنتور کوتاه می‌ماند.
- جاوااسکریپت وانیلا و بدون وابستگی؛ یک شنوندهٔ رخداد برای همهٔ تب‌ها (event delegation)، `ResizeObserver` به‌جای `resize`، و محاسبات چیدمان داخل `requestAnimationFrame`.
- تصاویر با `wp_get_attachment_image` رندر می‌شوند (srcset + width/height برای جلوگیری از پرش چیدمان). تصاویر تب فعال `eager`/`fetchpriority=high` و بقیه `lazy` هستند.
- `has_widget_inner_wrapper()` غیرفعال است تا لایهٔ اضافی در DOM ساخته نشود.
- همهٔ پنل‌ها در HTML حاضرند (برای سئو و دسترس‌پذیری) و تعویض تب بدون درخواست شبکه انجام می‌شود.
- `prefers-reduced-motion` رعایت می‌شود.

## دسترس‌پذیری

الگوی `tablist` / `tab` / `tabpanel` با `aria-selected`، `aria-controls`، `aria-labelledby` و مدیریت `tabindex`.
پیمایش با کلیدهای ← → (آگاه به جهت RTL)، `Home`، `End` و انتخاب با `Enter` / `Space`.

## پیش‌نمایش بدون وردپرس

فایل `preview.html` در ریشهٔ پروژه، همان HTML خروجی ویجت را با همین CSS/JS نمایش می‌دهد؛
برای بررسی سریع حالت‌های مختلف (پنل یک/دو/سه ستونه، دو تصویر بدون متن) کافی است در مرورگر باز شود.
سه قاب با عرض‌های متفاوت رندر می‌شوند و لبهٔ هر قاب قابل کشیدن است، پس شکستن چیدمان را می‌شود زنده دید.
